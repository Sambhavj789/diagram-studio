# Current state

## Verified

- Date: **2026-10-22**
- Gate: `node verify.js` — docs, links, CODEMAP coverage, 17 core checks, CLI smoke.
- Browser: Edge headless render + a Playwright run of theme toggle, file download,
  example switch, wheel zoom, reload/autosave. No console errors.
- Exports: SVG opens standalone with background and markers; PNG 2× (~110 KB for the
  default example) is not blank.

## Working

- DSL: shapes, labels, `\n`, quotes, groups, comments, tree mode, `graph`/`flowchart`.
- Edge styles: solid, dashed, two-way, self loops, rank-skipping lanes.
- Layout: layered, deterministic, no same-rank overlap; bounded canvas.
- UI: live render, error line numbers, pan/zoom, fit, light/dark, autosave, direction
  rewrite, SVG and 2× PNG download.
- CLI: file/stdin, theme/direction overrides, exit codes, summary line.
- Docs: this kit + root `AGENTS.md`; architecture/module diagrams generated by the tool.
- Samples: `out/report.svg`, `out/company.svg`, `out/weekly.svg`, `out/preview.png`.

## Known limits

- `RL`/`BT` render as `LR`/`TB`.
- Groups are visual only, effectively one nesting level; boxes can overlap when nested.
- No obstacle-avoiding routing; dense graphs can still look busy. Rank-skipping edges use
  outside lanes.
- Very wide ranks do not wrap.
- Edge-label bounds use the label anchor, not the full label width; a very long label at
  the far right can clip.
- Two SVGs embedded in one page share the marker id `ds-arrow`; differing themes can leak
  an arrow color.
- No undo, no drag editing, no multi-page output.
- PNG needs browser canvas; no server-side rasterizer.

## Next (proposed, not started)

1. Markdown outline → tree diagram in the CLI (books/notes use case).
2. `--scale 1|2|3` for PNG and an option for a transparent background.
3. Prefix marker ids with a render id to allow multiple diagrams per page.
4. Optional label bbox in bounds, then add a regression test.
5. Reuse this docs kit (`docs/` + `verify.js`) as the template for other small tools.

## Not planned

Mermaid parity, sequence/ER/Gantt diagrams, collaborative editing, remote fonts or images,
a hosted service.
