## Working

- DSL: shapes, labels, `\n`, quotes, groups, comments, tree mode, `graph`/`flowchart`.
- Edge styles: solid, dashed, two-way, self loops, rank-skipping lanes.
- Layout: layered, deterministic, no same-rank overlap; bounds include edge curves and
  full label boxes, so long labels are not clipped.
- UI: live render, error line numbers, pan/zoom, fit, light/dark, autosave, direction
  rewrite, PNG scale 1x/2x/3x, Clear background, SVG and PNG download.
- CLI: file/stdin, theme/direction overrides, `--json`, `--outline`/`--md`, `--book`,
  PNG output (`--png`, `--scale`, `--transparent`), exit codes, summary line.
- Outline: Markdown headings + lists and book yaml (parts + notes) become tree diagrams.
- Marker ids are per-render (`ds-arrow-<hash>`), so several diagrams with different themes
  can share one HTML page.
- Docs: this kit + root `AGENTS.md` + `INTEGRATIONS.md`; architecture/module diagrams
  generated by the tool.
- Samples: `out/report.svg`, `out/company.svg`, `out/weekly.svg`, `out/preview.png`.

## Known limits

- `RL`/`BT` render as `LR`/`TB`.
- Groups are visual only, effectively one nesting level; boxes can overlap when nested.
- No obstacle-avoiding routing; dense graphs can still look busy. Rank-skipping edges use
  outside lanes.
- Very wide ranks do not wrap.
- PNG needs an installed Chromium browser (Edge/Chrome); no bundled rasterizer. The UI
  caps the longest side at 6000 px; the CLI trusts `--scale` (1-3).
- Outline mode ignores paragraphs, blockquotes and tables; it reads headings and lists.
- No undo, no drag editing, no multi-page output.
